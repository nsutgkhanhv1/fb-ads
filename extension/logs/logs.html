Log & báo lỗi

AMIT tự ghi lại mọi thao tác, kết quả và lỗi. Bạn không cần làm gì cho đến khi gặp sự cố.

Khi tính năng chạy sai hoặc báo lỗi:
  1. (Không bắt buộc) Mô tả ngắn bạn đã làm gì và thấy gì khác với mong đợi.
  2. Bấm Xuất file log. File AMIT-log-….txt sẽ được tải về máy.
  3. Gửi file đó cho người phát triển.

File log có ID tài khoản quảng cáo và UID Facebook (cần để tìm lỗi). Token, cookie, API key và tên người dùng đã được che.
